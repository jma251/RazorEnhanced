1.0.0.1402 – 10 September 2026

  • Self-updating. Razor now checks this fork for new builds on startup and offers to install them, instead of needing a zip downloaded and copied over by hand. The updater was always built in; it was pointed at the upstream project, so it could never see a build from here.
  • Version numbers now change per build. Every build was reporting 1.0.0.14, which meant an updater could never tell one from the next. Builds are now numbered 1.0.0.1402, 1.0.0.1403 and so on – "14" is the upstream version this fork is based on, the last two digits are the build.
  • This changelog. Generated on every build and shown in Razor's ChangeLog window.

Upgrading to this build has to be done by hand one last time – an older install still checks the upstream project for updates. Every build after this one updates itself.

Sound filters – 10 September 2026

  • Six new filters: Satyr, Bear, Walrus, Wolf, Snow Leopard and Charlie. Each can be switched on in the Filters tab, so these no longer need silencing by editing sound.mul after every client patch.
  • Bear and Wolf cannot be split by type. Black, grizzly and polar bears share one set of sounds, as do dire, grey, timber and white wolves. The filter names say so.
  • Dog, Horse and Sheep were only filtering two of their five sounds. When these moved from code into a settings file in 2021 the ranges were copied across as just their first and last entries, so the three middle sounds of each were never silenced. Cat had the same fault and was fixed in 2022; the other three were missed.
  • Bull, Chicken and Deer were off by one and had been since 2019. Each missed one of its own sounds and silenced one belonging to something else – "Deer Sounds" was muting a dragon attack and a drinking sound.
  • Every sound ID was checked against the client's own sound table. No ID is now claimed by two filters.

Movement key hotkeys fixed – 10 August 2026

  • Hotkeys bound to End, Page Down, Page Up, Home and the arrow keys did nothing. Razor ignores those keys while it is walking your character for a script, so its own keystrokes cannot trigger your hotkeys – but the switch that turns this on was never turned back off. It latched on at your first step and stayed on for the rest of the session, throwing those hotkeys away before they were ever looked up. Delete and the F-keys were unaffected, which is why only the movement keys appeared broken.

Automatic builds – 10 August 2026

  • Every change pushed to this fork is now built automatically and published as a downloadable zip, with the same download link each time.
  • The build checks that everything Razor needs to actually run is in the zip before publishing, rather than shipping one that fails on launch.
